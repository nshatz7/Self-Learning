# Systems, Algorithms & Cloud Architecture — Engineering Log

> *"First, solve the problem. Then, write the code."*

Welcome! This repository is a living logbook of my self-taught journey through computer science fundamentals, algorithmic problem-solving, and cloud architecture. 

Rather than just dumping raw code or chasing a high problem count, this repo is built around **first-principles understanding**. Every solution, course module, and architectural diagram here is accompanied by written breakdowns of *why* an approach works, the time/space trade-offs involved, and what broke along the way.
