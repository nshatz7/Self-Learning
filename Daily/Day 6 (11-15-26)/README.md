## Core Daily Question

> **What is sorting first ($O(n \log n)$), fixing a base index, and running two pointers while skipping duplicates?**

The **Sort + Two Pointers** pattern follows 4 steps:

1. **Sort** the array using `.sort()`.
2. **Fix** a base index `i`.
3. **Run** two pointers: `left` and `right`.
4. **Skip** the duplicates.
