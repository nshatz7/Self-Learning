## Core Daily Question

> Q: What is bi-directional mapping validation using dual hash maps or index maps, and why is it helpful?

* Bi-directional mapping validation using dual hash maps or index maps is very helpful when having a one-to-one rule between two strings (like a pattern) because you can use it to validate the rule with equality between the two hash maps or index maps.
